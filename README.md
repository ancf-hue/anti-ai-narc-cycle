## ✨ Особенности

- 🔍 **Детекция 4 фаз цикла**: Идеализация → Обесценивание → Отвержение → Возврат
- 📊 **Хронология и прогноз**: анализ паттернов в локальном журнале
- 🧠 **Тренажёр диалогов**: интерактивные сценарии для отработки распознавания
- 📓 **Инструменты восстановления**: дневник КПТ, таблица доказательств, карта границ
- 🔒 **100% офлайн**: все данные хранятся только в вашем браузере (localStorage)
- 👁 **Скрытый режим**: защита интерфейса PIN-кодом
- 📤 **Экспорт данных**: JSON / CSV / TXT для работы с психологом
- 🌍 **Русский интерфейс**: адаптировано под культурный контекст
